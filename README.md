# Dolphin Logic

**Five cards. One unexpected direction.**

[**Open Dolphin Logic in your browser**](https://quick-eyed-sky.github.io/dolphin-logic/)

A small creative instrument for stories, images and music, in a warm, quiet interface. Draw five cards, keep the ones that speak to you, and change the others.

## Three ways in

- **Story:** Figure · Tension · Place · Method · Perspective.
- **Image:** Presence · Relationship · Atmosphere · Treatment · Reading.
- **Music:** Voice · Motion · Space · Technique · Form.

There are **225 journal motifs**, arranged in five families of 45. Each motif has a separately written English rendering for the three media: **675 medium-specific cards** in all. These are three interpretations of the source material, not 675 independent ideas. A draw has exactly five cards: one per family. Each mode has **184,528,125** possible combinations.

## Use it

- **New draw** replaces the cards you have not held. The space bar does the same when you are not using another control.
- **Hold** keeps a card in place; **Swap** changes just that card.
- **Undo** restores the preceding change.
- **The deck** lets you browse, search and deliberately choose a card.
- **Journal** opens the source idea in English and the original French passage.
- **Copy brief** takes the combined prompt to your own workspace.
- **Keep this draw** saves a combination in this browser.
- **Export / Import** moves draws or collections between browsers.
- **Download the standalone page** saves the complete app as one HTML file.

## One file, no setup

The application is entirely in [`index.html`](index.html): interface, styles, dolphin mark, all card text and source passages. There is no build step, package manager, account, API key or external runtime dependency. It makes no automatic network calls.

Open the hosted app, or download `index.html` and open it in a browser. Saves are local to the browser and origin; use the collection export to move them between the online and downloaded editions. If browser storage is unavailable, the app keeps working for the session and offers an export.

## Where the ideas come from

The source material is the **Journal Maison-Page**: observations, story seeds, images, musical devices, questions, quotations and ways of living. The collection links to **123 source fragments** and incorporates the earlier fifty ideas for living developed from that material.

Each source panel distinguishes the journal idea, conservatively paraphrased in English, from its reformulation or transposition for the selected medium. The original French is available for comparison. Neutral reference labels replace calendar references; ellipses mark omissions. Identified third-party quotations retain their attribution.

The sideways approach acknowledges **Brian Eno and Peter Schmidt's Oblique Strategies**. The dolphin refers to a framework attributed in the journal to *La Stratégie du Dauphin*. The card wording here was prepared for Dolphin Logic. The draft's external tarot interpretations were removed in the source-checked edition.

## Checks

All 675 card inputs and their assembled briefs were checked. Every card has a source; the bank contains 45 cards in each family for each mode. Browser checks cover the main interactions, source panels, saves, copying, export/import and a narrow phone layout. The delivered file embeds its runtime resources.
